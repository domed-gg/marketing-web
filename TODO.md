Key GDPR Requirements You Should Be Aware Of:

To fully comply with EU data protection law (GDPR), you'll need to ensure the following:

Data Processing Agreement (DPA) - If you use third-party processors (hosting, payment providers), you need DPAs with them.

Data Protection Officer (DPO) - Consider appointing one if you process data on a large scale (may not be required for smaller operations).

Record of Processing Activities - Maintain internal documentation of all data processing activities (Article 30).

Data Breach Notification - You must notify the supervisory authority within 72 hours of becoming aware of a data breach, and affected individuals without undue delay if high risk.

Privacy by Design - Implement data protection measures from the start of any project (you're already doing this with server-side processing).

Subject Access Requests (SARs) - Be prepared to respond to data subject requests within 1 month (extendable to 3 months for complex requests).

Lawful Basis Documentation - Document which lawful basis applies to each processing activity.

Cookie Consent - If your website uses cookies beyond essential ones, you'll need a cookie consent banner.

International Transfers - If data leaves the EEA, ensure Standard Contractual Clauses (SCCs) or other approved mechanisms are in place.

Contact Email - Set up privacy@domed.ac as mentioned in the policy to handle privacy inquiries.
